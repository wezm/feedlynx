# Contributing

Thanks for your interest in contributing to `feedlynx`. Here are some
guidelines for making a contribution:

- Please open an issue to discuss larger changes first.
- Please add tests for new functionality where it makes sense.
- Ensure your code is formatted with `rustfmt` (`cargo fmt`).
- Ensure code and dependencies are compatible with the minimum supported
  Rust version. This is documented by the `rust-version` key in `Cargo.toml`.

**Note:** Contributions that are generated using tools like LLMs/"AI" are not
accepted. Please also refrain from using such tools to generate issues, pull
requests, and commits.
